## November 18, 2026 — #2914. Minimum Number of Changes to Make Binary String Beautiful

**LeetCode:** https://leetcode.com/problems/minimum-number-of-changes-to-make-binary-string-beautiful/

**Chosen approach:** Greedy: check pairs at indices `(0,1)`, `(2,3)`, etc. One flip per mismatched pair.

**Complexity:** Time O(n); extra space O(1).

**Example:** `minChanges("1001")` → `2`

### Final JavaScript

```javascript
var minChanges = function(s) {
    let changes = 0;

    for (let i = 0; i < s.length; i += 2) {
        if (s[i] !== s[i + 1]) {
            changes++;
        }
    }

    return changes;
};
```

## November 19, 2026 — #2567. Minimum Score by Changing Two Elements

**LeetCode:** https://leetcode.com/problems/minimum-score-by-changing-two-elements/

**Chosen approach:** Ideal O(n) version: track only the three smallest and three largest values, then compare the three ways to change extremes.

**Complexity:** Time O(n); extra space O(1).

**Example:** `minimizeSum([1,4,7,8,5])` → `3`

### Final JavaScript

```javascript
var minimizeSum = function(nums) {
    const smallest = [];
    const largest = [];

    for (const num of nums) {
        smallest.push(num);
        smallest.sort((a, b) => a - b);
        if (smallest.length > 3) smallest.pop();

        largest.push(num);
        largest.sort((a, b) => b - a);
        if (largest.length > 3) largest.pop();
    }

    return Math.min(
        largest[0] - smallest[2], // Change the two smallest.
        largest[1] - smallest[1], // Change the smallest and largest.
        largest[2] - smallest[0]  // Change the two largest.
    );
};
```

## November 20, 2026 — #3041. Maximize Consecutive Elements in an Array After Modification

**LeetCode:** https://leetcode.com/problems/maximize-consecutive-elements-in-an-array-after-modification/

**Chosen approach:** No-sort version we ended on: frequency map, possible final-value set, and DP that processes each real copy.

**Complexity:** Time O(n) expected; extra space O(n).

**Example:** `maxSelectedElements([2,1,5,1,1])` → `3`

### Final JavaScript

```javascript
var maxSelectedElements = function(nums) {
    const freq = new Map();
    const possible = new Set();
    const dp = new Map();
    let best = 0;

    for (const x of nums) {
        freq.set(x, (freq.get(x) ?? 0) + 1);
        possible.add(x);
        possible.add(x + 1);
    }

    // Process one real copy of x: either keep x or increase it to x + 1.
    function update(x) {
        // Read both BEFORE writing, so this input element is not used twice.
        const prev = dp.get(x - 1) ?? 0;
        const curr = dp.get(x) ?? 0;

        const keep = prev + 1;
        const inc = curr + 1;

        dp.set(x, keep);
        dp.set(x + 1, inc);
        best = Math.max(best, keep, inc);
    }

    for (const start of possible) {
        // Each consecutive group is processed from its smallest possible value.
        if (possible.has(start - 1)) continue;

        let x = start;
        while (possible.has(x)) {
            const copies = freq.get(x) ?? 0;
            for (let copy = 0; copy < copies; copy++) {
                update(x);
            }
            x++;
        }
    }

    return best;
};
```

## November 21, 2026 — #3331. Find Subtree Sizes After Changes

**LeetCode:** https://leetcode.com/problems/find-subtree-sizes-after-changes/

**Chosen approach:** Recursive DFS over the original tree. Give each child `new Map(last)` to avoid ancestor-map restoration.

**Complexity:** Time O(n) (fixed alphabet); extra space O(n) (including recursive frames).

**Example:** `findSubtreeSizes([-1,0,0,1,1,1], "abaabc")` → `[6,3,1,1,1,1]`

**Implementation note:** This is the recursive version we preferred. A path-shaped tree with 100,000 nodes can exceed JavaScript’s recursion limit; use the iterative variant if LeetCode rejects deep recursion.

### Final JavaScript

```javascript
var findSubtreeSizes = function(parent, s) {
    const n = parent.length;
    const kids = Array.from({ length: n }, () => []);
    const size = new Array(n).fill(1);

    for (let node = 1; node < n; node++) {
        kids[parent[node]].push(node);
    }

    function dfs(node, last) {
        const char = s[node];
        let newParent = parent[node];

        if (last.has(char)) {
            newParent = last.get(char);
        }

        // This map belongs only to the current recursive call.
        last.set(char, node);

        for (const child of kids[node]) {
            dfs(child, new Map(last));
        }

        // Add this completed subtree to its parent in the MODIFIED tree.
        if (newParent !== -1) {
            size[newParent] += size[node];
        }
    }

    dfs(0, new Map());
    return size;
};
```

## November 22, 2026 — #2124. Check if All A's Appears Before All B's

**LeetCode:** https://leetcode.com/problems/check-if-all-as-appears-before-all-bs/

**Chosen approach:** Track whether a `b` has appeared; any subsequent `a` makes the answer false.

**Complexity:** Time O(n); extra space O(1).

**Example:** `checkString("abab")` → `false`

### Final JavaScript

```javascript
var checkString = function(s) {
    let seenB = false;

    for (const char of s) {
        if (char === 'b') {
            seenB = true;
        }
        if (char === 'a' && seenB) {
            return false;
        }
    }

    return true;
};
```

## November 23, 2026 — #1352. Product of the Last K Numbers

**LeetCode:** https://leetcode.com/problems/product-of-the-last-k-numbers/

**Chosen approach:** Prefix products since the latest zero, with division for `getProduct(k)`.

**Complexity:** Time add O(1) amortized, getProduct O(1); extra space O(n).

**Example:** After `add(3), add(0), add(2), add(5), add(4)`: `getProduct(2)` → `20`; `getProduct(4)` → `0`

### Final JavaScript

```javascript
class ProductOfNumbers {
    constructor() {
        this.prefix = [1];
    }

    add(num) {
        if (num === 0) {
            this.prefix = [1];
            return;
        }

        const last = this.prefix[this.prefix.length - 1];
        this.prefix.push(last * num);
    }

    getProduct(k) {
        const count = this.prefix.length - 1;

        if (k > count) {
            return 0;
        }

        const total = this.prefix[count];
        const before = this.prefix[count - k];
        return total / before;
    }
}
```

## November 24, 2026 — #3411. Maximum Subarray With Equal Products

**LeetCode:** https://leetcode.com/problems/maximum-subarray-with-equal-products/

**Chosen approach:** Scan all starts, extending the end while updating product, GCD, and LCM; stop when equality can no longer return.

**Complexity:** Time O(n²) for stated bounded values; extra space O(1).

**Example:** `maxLength([2,3,4,5,6])` → `3`

### Final JavaScript

```javascript
var maxLength = function(nums) {
    function gcd(a, b) {
        while (b !== 0) {
            const rem = a % b;
            a = b;
            b = rem;
        }
        return a;
    }

    function lcm(a, b) {
        return (a / gcd(a, b)) * b;
    }

    let best = 0;

    for (let left = 0; left < nums.length; left++) {
        let prod = 1;
        let gcdVal = 0;
        let lcmVal = 1;

        for (let right = left; right < nums.length; right++) {
            const num = nums[right];
            prod *= num;
            gcdVal = gcd(gcdVal, num);
            lcmVal = lcm(lcmVal, num);

            const target = gcdVal * lcmVal;

            if (prod === target) {
                best = Math.max(best, right - left + 1);
            } else if (prod > target) {
                break;
            }
        }
    }

    return best;
};
```

## November 25, 2026 — #3934. Smallest Unique Subarray

**LeetCode:** https://leetcode.com/problems/smallest-unique-subarray/

**Chosen approach:** Our final refactored suffix automaton: node IDs, `splitNode()`, one transition-exists check in the main loop, and occurrence propagation through the shorter-ID tree.

**Complexity:** Time O(n) expected; extra space O(n).

**Example:** `smallestUniqueSubarray([1,2,1,2,1])` → `3`

**Our agreed naming:** `currNum`, `newId`, `lastId`, `shorterId`, `nextId`, `cloneId`, `ROOT_ID`, `NO_ID`. Node transitions use plain JavaScript objects (`next: {}`).

### Final JavaScript

```javascript
var smallestUniqueSubarray = function(nums) {
    const ROOT_ID = 0;
    const NO_ID = -1;
    const nodes = [
        { maxLength: 0, shorterId: NO_ID, next: {}, occurrenceCount: 0 }
    ];
    let lastId = ROOT_ID;

    // Copy an existing node's transitions into a clone, but split off only
    // the shorter paths. A clone is NOT a new input position (count = 0).
    function splitNode(shorterId, nextId, currNum) {
        const cloneId = nodes.length;

        nodes.push({
            maxLength: nodes[shorterId].maxLength + 1,
            shorterId: nodes[nextId].shorterId,
            next: { ...nodes[nextId].next },
            occurrenceCount: 0
        });

        // Redirect all shorter-path transitions that still point at nextId.
        while (
            shorterId !== NO_ID &&
            nodes[shorterId].next[currNum] === nextId
        ) {
            nodes[shorterId].next[currNum] = cloneId;
            shorterId = nodes[shorterId].shorterId;
        }

        nodes[nextId].shorterId = cloneId;
        return cloneId;
    }

    // Build the suffix automaton one input number at a time.
    for (const currNum of nums) {
        const newId = nodes.length;

        nodes.push({
            maxLength: nodes[lastId].maxLength + 1,
            shorterId: NO_ID,
            next: {},
            occurrenceCount: 1
        });

        // If no existing transition is found, root is the default.
        nodes[newId].shorterId = ROOT_ID;
        let shorterId = lastId;

        while (shorterId !== NO_ID) {
            const nextId = nodes[shorterId].next[currNum];
            const transitionExists = nextId !== undefined;

            if (transitionExists) {
                const expectedLength = nodes[shorterId].maxLength + 1;
                const actualLength = nodes[nextId].maxLength;
                const needsClone = expectedLength !== actualLength;

                nodes[newId].shorterId = needsClone
                    ? splitNode(shorterId, nextId, currNum)
                    : nextId;

                break;
            }

            nodes[shorterId].next[currNum] = newId;
            shorterId = nodes[shorterId].shorterId;
        }

        lastId = newId;
    }

    // Turn shorterId links into a parent -> children tree.
    const children = Array.from({ length: nodes.length }, () => []);
    for (let id = 1; id < nodes.length; id++) {
        const parentId = nodes[id].shorterId;
        children[parentId].push(id);
    }

    // Visit parents first, then reverse this order when propagating counts.
    const stack = [ROOT_ID];
    const visitOrder = [];

    while (stack.length > 0) {
        const id = stack.pop();
        visitOrder.push(id);

        for (const childId of children[id]) {
            stack.push(childId);
        }
    }

    // Propagate each node's occurrence count to its shorter-node parent.
    for (let index = visitOrder.length - 1; index > 0; index--) {
        const childId = visitOrder[index];
        const parentId = nodes[childId].shorterId;
        nodes[parentId].occurrenceCount += nodes[childId].occurrenceCount;
    }

    // Find the shortest length represented by a node occurring exactly once.
    let minUniqueLength = nums.length;

    for (let id = 1; id < nodes.length; id++) {
        const appearsExactlyOnce = nodes[id].occurrenceCount === 1;
        if (!appearsExactlyOnce) continue;

        const shorterId = nodes[id].shorterId;
        const shortestLength = nodes[shorterId].maxLength + 1;
        minUniqueLength = Math.min(minUniqueLength, shortestLength);
    }

    return minUniqueLength;
};
```


### Alternative JavaScript — Suffix Array + LCP (no automaton)

**Why include it:** We also studied this approach and wanted to retain it alongside the O(n) automaton.

**Approach:** Sort suffix start indices using rank doubling and stable counting sort; calculate adjacent longest-common-prefix values (LCP); then find the shortest distinguishing prefix for each suffix. There is **no binary search** and **no automaton cloning**.

**Complexity:** Time O(n log n); extra space O(n).

**Function:** `smallestUniqueSubarraySuffixArray(nums)` (separate name to keep both implementations in the same file).

**Example data:**

```javascript
nums = [1, 2, 1, 2, 1];
sa = [4, 2, 0, 3, 1];
lcp = [0, 1, 3, 0, 2];
needed = [2, 4, 4, 3, 3];
available = [1, 3, 5, 2, 4];
validLengths = [4, 3];
answer = 3;
```

| Sorted suffix | LCP prev | LCP next | Needed | Available | Valid? |
|---|---:|---:|---:|---:|---|
| `[1]` | 0 | 1 | 2 | 1 | No |
| `[1,2,1]` | 1 | 3 | 4 | 3 | No |
| `[1,2,1,2,1]` | 3 | 0 | 4 | 5 | Yes |
| `[2,1]` | 0 | 2 | 3 | 2 | No |
| `[2,1,2,1]` | 2 | 0 | 3 | 4 | Yes |

**Shortest unique prefix formula:** `needed = max(lcp[i], lcp[i + 1] ?? 0) + 1`. A suffix is valid if `needed <= n - sa[i]`.

```javascript
var smallestUniqueSubarraySuffixArray = function(nums) {
    const n = nums.length;
    if (n === 1) return 1;

    // STEP 1: Give equal numbers equal ranks.
    const sortedValues = [...nums].sort((a, b) => a - b);
    const valueRank = Object.create(null);
    let groups = 0;

    for (const num of sortedValues) {
        if (valueRank[num] === undefined) {
            valueRank[num] = groups;
            groups++;
        }
    }

    let rank = nums.map(num => valueRank[num]);
    let sa = Array.from({ length: n }, (_, i) => i);

    // Stable counting sort for one half of a rank pair.
    // A missing second half has rank -1, ordered before other ranks.
    function countSort(indices, offset) {
        const count = new Int32Array(groups + 1);

        for (const start of indices) {
            const key = start + offset < n ? rank[start + offset] + 1 : 0;
            count[key]++;
        }

        let position = 0;
        for (let key = 0; key < count.length; key++) {
            const size = count[key];
            count[key] = position;
            position += size;
        }

        const result = new Array(n);
        for (const start of indices) {
            const key = start + offset < n ? rank[start + offset] + 1 : 0;
            result[count[key]++] = start;
        }
        return result;
    }

    // STEP 2: Sort suffixes by doubling the compared prefix length.
    // First sort by the second half, then the first half.
    for (let gap = 1; gap < n; gap *= 2) {
        sa = countSort(sa, gap);
        sa = countSort(sa, 0);

        const nextRank = new Array(n);
        nextRank[sa[0]] = 0;
        let newGroups = 1;

        for (let i = 1; i < n; i++) {
            const prev = sa[i - 1];
            const curr = sa[i];
            const prevSecond = prev + gap < n ? rank[prev + gap] : -1;
            const currSecond = curr + gap < n ? rank[curr + gap] : -1;

            const different = rank[prev] !== rank[curr] || prevSecond !== currSecond;
            if (different) newGroups++;
            nextRank[curr] = newGroups - 1;
        }

        rank = nextRank;
        groups = newGroups;
        if (groups === n) break;
    }

    // STEP 3: Calculate LCP between neighboring sorted suffixes.
    // lcp[i] is the common prefix length of sa[i-1] and sa[i].
    const pos = new Array(n);
    for (let i = 0; i < n; i++) {
        pos[sa[i]] = i;
    }

    const lcp = new Array(n).fill(0);
    let common = 0;

    for (let start = 0; start < n; start++) {
        const i = pos[start];
        if (i === 0) {
            common = 0;
            continue;
        }

        const prevStart = sa[i - 1];
        while (start + common < n && prevStart + common < n && nums[start + common] === nums[prevStart + common]) {
            common++;
        }

        lcp[i] = common;
        if (common > 0) common--;
    }

    // STEP 4: The first unique prefix has length max(neighbor LCPs) + 1.
    let best = n;

    for (let i = 0; i < n; i++) {
        const prevLcp = lcp[i];
        const nextLcp = lcp[i + 1] ?? 0;
        const needed = Math.max(prevLcp, nextLcp) + 1;
        const available = n - sa[i];

        if (needed <= available) {
            best = Math.min(best, needed);
        }
    }

    return best;
};
```
